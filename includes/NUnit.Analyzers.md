> [!IMPORTANT]\
> NUnit.Analyzers depends not only on Microsoft.CodeAnalysis.CSharp but also on NUnit,
> so the latest version usable in Unity is **v3.9.0**.

> [!TIP]\
> You can install the UPM package that bundles NUnit.Analyzers, called [NUnit.Analyzers for Unity](https://github.com/nowsprinting/nunit.analyzers.unity).
> You do not need to manually add a reference to the test assembly definition file (asmdef).

> [!TIP]\
> You can also install the [UPM package that bundles UTFAnalyzers](https://openupm.com/packages/com.nowsprinting.test-framework.analyzers/), which includes NUnit.Analyzers v3.9.0.
